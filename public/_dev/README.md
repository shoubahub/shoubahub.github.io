# أدوات التطوير — لا تُنشر

| الأداة | ما تفعل |
|---|---|
| `demo-seed.html` | تبذر بيانات تجريبية وتمسح الحقيقية — **محروسة: لا تعمل خارج الجهاز المحلّي** |
| `board-sim.html` | معاينة اللوحة بساعة ثابتة (الأحد ١٠:٥٠) لرؤية حالات الدوام خارج وقته |
| `diag.html` | تشخيص الجهاز والمتصفّح |
| `kit.html` | معرض المكوّنات |
| `page-sim.html?p=<شاشة>&seed` | **معاينة المنصة كلها** بلا دخول ببيانات مثال (أربعة معلمين · ثلاثة محاضر · خطتان تشغيليتان للفصل الحالي والسابق) — تبدأ من الشاشة المطلوبة (`records.html` افتراضا) **وتتنقل بين الشاشات كما في المنصة** (راية جلسة `shouba.sim` يقبلها حارس الجلسة على localhost وحده). `&seed` يعيد المثال ولو امتلأ المخزن · `&seed=prev` خطة الفصل السابق وحدها (لمعاينة النسخ) |
| `blocks-sim.html?filled` · `?filled&print` | لبنات السجلات إدخالا وورقا من التعريف — و`&print` الورقة وحدها بمقاسها لفحص الطباعة |
| `print-sample.html` | عينة الترويسة بثلاثة خطوط — مرجع قرار خط الورق «بلكس» (2026-09-12) |
| `rec-test.mjs` | اختبار نواة محرك السجلات: `node public/_dev/rec-test.mjs` (واختبار المرفقات في الخادم: `node tests/files-test.js`) |
| `plain.mjs --dry` | فحص خلو الملفات من التشكيل (يجب ٠) |

**⚠ عامل الخدمة يخدم JS قديما على localhost:** قبل التحقق ألغ تسجيله وامسح مخزنه من أدوات المتصفح.

**⚠ عند النشر: استبعد هذا المجلّد كاملاً.** أُخرجت من جذر `public` في تنقية 2026-09-05 استعداداً للتجربة الميدانية.
